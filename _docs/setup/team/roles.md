The Roles tab provides you with a pageable and filterable worklist of all the [roles](/docs/roles/) you have set up in Cerb. From here you can view, manage, and add new roles. You can also click any entry in the list to go to its profile page.

The same info and functionality can be accessed from **Search** >> **Roles**.
