The data query tester is used for testing and executing data queries outside of widgets, sheets, or automations. With full autocomplete functionality, you can explore your data without limitations imposed by the specific widget or automation used.

One of its key benefits is the ability to see the output of any given data query, helping you quickly identify issues that prevent desired results. By leveraging this feature, you can efficiently debug errors and fine-tune your queries with confidence.

## Access

The data query tester can be accessed by clicking **Setup >> Developers >> Data Query Tester**. 

## Usage

You can use autocomplete to help build any query you want in the query tester box, or you can copy and paste an existing query directly from another source and click the **Run** button to see the results.
