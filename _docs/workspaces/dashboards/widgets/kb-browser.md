The **Knowledgebase Browser** widget embeds a category tree of knowledgebase articles directly on a dashboard. Workers can drill into categories and open articles inline without leaving the workspace -- useful for keeping team playbooks, FAQ collections, and reference material a click away.

# Configuration

| Field | Description
|-|-
| Start the knowledgebase browser at this category | Pick a category to scope the browser. Choose **- show all -** to display the full tree, or select a specific category to focus the widget on its sub-tree.

The widget is provided by the `cerberusweb.kb` plugin, which must be installed and enabled.
