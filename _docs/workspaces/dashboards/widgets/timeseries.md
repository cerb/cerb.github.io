The **Time Series** chart widget displays a chart designed to visualize changes in data over time.

<div class="cerb-screenshot">
<img src="/assets/images/docs/dashboards/widgets/timeseries/timeseries.png" class="screenshot">
</div>

## Configuration

Configuration options for time series widgets include the format of the chart (line, spline, area, bar), labels for the axes, whether or not to display a legend, and a `hidden@bool:` statement for conditional hiding.
