The **Data Query Tester** gives you the opportunity to test or run any data query outside of widgets, sheets or automations with full autocomplete functionality. Autocomplete can be limited based on the widget or automation you are using, so the Data Query tester can give you full flexibility without any such limitations. You can also easily see the output of any given data query if something isn't working out as you expect. This can help you debug any errors.

## Access

The Data Query Tester can be accessed by clicking **Setup > Developers > Data Query Tester.** 

## Usage

You can use autocomplete to help build any query you want in the query tester box, or you can copy and paste an existing query directly from another source and click the **Run** button to see the results.
